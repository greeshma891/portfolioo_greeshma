# Greeshma Aitha — Dynamic SVG Portfolio

A responsive portfolio built with pure HTML, CSS and JavaScript.

## Included
- Animated SVG hero artwork
- SVG project illustrations
- Mouse-follow glow
- Scroll reveal animations
- Magnetic CTA
- Project tilt interaction
- Responsive mobile navigation
- Skills orbit
- Timeline
- Contact section

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Personal details
Content is based on the uploaded resume. Update the LinkedIn placeholder in `index.html`.
